# Site Reliability Engineering — Hands-on Learning Portfolio

A structured, practical learning portfolio documenting SRE fundamentals and progressively implemented reliability labs using AWS, Kubernetes, Prometheus, Grafana, and automation.

> **Status:** Phase 1 conceptual learning completed. Phase 2 practical implementations are planned. Examples are educational simulations, not claims about production systems.

## Learning roadmap

| Phase | Scope | Status |
|---|---|---|
| 01 | SRE fundamentals | Conceptual assessment completed |
| 02 | Monitoring and observability | Planned |

| 04 | Kubernetes and cloud reliability | Planned |

| 07 | Interview and career readiness | Planned |

## Phase 1 learning

See [Phase 1 — SRE Fundamentals](phase-01-sre-fundamentals/README.md) for ten lessons, example calculations and a simulated incident assessment.

## Engineering evidence

As hands-on labs are completed, this repository will include executable configurations, validation steps, screenshots, troubleshooting notes, and cleanup instructions. Only tested implementations will be marked **Validated**.

## Safety and disclosure

Use isolated lab environments. Do not commit passwords, tokens, customer data, employer configurations, private addresses, or sensitive production logs. Never perform unapproved changes in production.
